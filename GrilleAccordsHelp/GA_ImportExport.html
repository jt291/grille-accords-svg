Aide Grille Accords
  Exportation Importation de Chansons

L'application Grille Accords gère un Livre de Chansons unique.

Il est toutefois possible de faire des copies de chansons, par exemple, pour les archiver, les dupliquer ou les échanger entre utilisateurs de l'application.

On procède alors a une Exportation ou a une Importation de Chansons.

Exportation

Menu: "Fichier/Exporter une Chanson…"
Menu: "Fichier/Exporter les Chansons d'un Chapitre…"

Lors d'une Exportation de Chansons un dialogue demande de sélectionner un dossier dans lequel sera enregistré un dossier contenant les chansons exportées.

Par exemple Exportation : la chanson : "Petit Navire" dont le code est : 

Structure =
3/8
Couplet : Il était un petit navire 
Couplet =
1: Gm . F . Gm .
1: Gm . D . Em .
1: Em .
1: D . .
1: F . .
1: Gm . .

Si on l'exporte, par exemple dans le dossier "…Archive" :
- un dossier est créé dans "…Archive" nommé par exemple :
    "2017-07-22-091518-Petit Navire"
- qui contiendra le fichier "Petit Navire.chanson"

Le nom de dossier "2017-07-22-091518-C" signifie que l'exportation a été effectuée le 22/07/2017 à 9h5mn18s

Le fichier "Petit Navire.chanson" est un fichier texte contenant le nom de la chanson "Petit Navire" sur la première ligne suivi par le code ci-dessus.

L'exportation d'un Chapitre exporte, de la même façon, toutes les Chansons qu'il contient dans un même dossier.

Toutes les chansons du chapitre "Divers", seront enregistrées dans un dossier nommé, par exemple :
    "2017-07-22-091725-[Divers]"

Importation

Menu: "Fichier/Importer des Chansons…"

Lors d'une Importation de Chansons un dialogue demande de sélectionner un ou plusieurs fichiers de Chansons, avec l'extension ".chanson"
Les Chansons importées seront toutes placées dans le chapitre sélectionné.

En cas de conflits sur les noms des chansons importées un suffixe "-copie" est ajouté au nom et une alerte est affichée dans la consolle.

Préférences : Dossier d'archivage

Pour les import-export, il est vivement conseillé de choisir un dossier d'archivage personnel unique qui permettra de faciliter les transferts de données entre utilisateurs de "Grille Accords"

Ce dossier peut être enregistré dans les Préférence de l'application :

Menu: "Grille Accords/Préférences…"

Une fois enregistré dans les Préférences, ce dossier sera automatiquement proposé par défaut dans les dialogues de sélection de fichiers ou dossier.
