Aide Grille Accords
  Grille d'accords d'une Chanson

La Chanson sélectionnée dans le Livre de Chansons est présentée sur la troisième colonne.

Sous le titre de cette Chanson on peut éditer la description de sa grille d'accords dans le langage présenté dans la rubrique Langage de description de grille d'accords

En bas de cette colonne, le bouton :   permet d'imprimer le code de la description.

Composition de la Grille

Un clic sur le bouton permet de vérifier la validité de cette description.

  • Si la description est correcte, la Grille est affichée sur le panneau de droite. De plus un petit bouton apparait à droite du titre de la chanson pour signaler que la description est valide.
  • Si la description est incorrecte, un message d'erreur est affichée sur la console qui souvre sous le code de description.

Console d'erreur

Dans la console l'erreur (panneau du bas sur fond jaune), l'erreur est décrite avec indication du numéro de ligne et du numéro dans la ligne, du mot sur lequel l'erreur s'est produite

Dans le code (panneau du haut) la ligne contenant l'erreur est sélectionnée. Il suffit de la corriger, puis de composer à nouveau...

La console peut être cachée à l'aide du bouton ou montrée à l'aide du bouton .

Récupération de la dernière description valide

Lors de la modification d'une description, des erreurs sont possibles. En cas de problème, il est possible de récupérer la dernière description valide par un clic sur le petit bouton apparu à droite du titre de la chanson quand une grille correcte a été affichée.
