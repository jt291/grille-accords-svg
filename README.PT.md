# Grille Accords SVG

[English](README.EN.md) · [Español](README.ES.md) · [Português](README.PT.md) · [العربية](README.AR.md) · [Brezhoneg](README.BR.md) · [中文](README.ZH.md) · [Français](README.FR.md) · [हिन्दी](README.HI.md) · [Kurdî](README.KU.md)

Transforme uma descrição textual compacta numa grelha de acordes clara e tocável, pronta para ensaiar, imprimir, ouvir e exportar.

## Funcionalidades

- editor com números de linha, posição do cursor e realce da linha ativa;
- diagnósticos bloqueadores que indicam a linha, a posição e o símbolo incorreto;
- pré-visualização SVG, transposição e reprodução Web Audio com metrónomo;
- exportação de texto, SVG, PNG, WebP, MIDI e MusicXML;
- impressão, ecrã inteiro, painéis redimensionáveis e modos claro/escuro;
- interface e ajuda disponíveis em nove idiomas.

## Instalação

Instale [Node.js](https://nodejs.org/) e [pnpm](https://pnpm.io/installation), depois execute cada passo:

```sh
git clone https://github.com/jt291/grille-accords-svg.git
cd grille-accords-svg
pnpm install
pnpm dev
```

A aplicação abre automaticamente em `http://localhost:4317/`.
