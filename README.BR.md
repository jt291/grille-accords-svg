Treuzfurmit un deskrivadur testenn berr en ur gael akordoù sklaer ha aes da seniñ, prest evit pleustriñ, moullañ, selaou hag ezporzhiañ.

## Arc’hwelioù

- embanner gant niverennoù linennoù, lec’h ar biz-red ha linennoù oberiant usskedet
- diagnostikoù a harz ar rentañ hag a verk al linenn, al lec’h hag an arouez faziek
- alberz SVG, treuzlec’hiañ ha lenn Web Audio gant metronom
- ezporzhioù testenn, SVG, PNG, WebP, MIDI ha MusicXML
- moullañ, skramm leun, panelloù adventadus ha modoù sklaer/teñval
- etrefas ha skoazell e nav yezh

## Staliañ

Stailhit [Node.js](https://nodejs.org/) ha [pnpm](https://pnpm.io/installation), goude-se sevenit pep pazenn :

```sh
git clone https://github.com/jt291/grille-accords-svg.git
cd grille-accords-svg
pnpm install
pnpm dev
```

Digoret e vez an arload ent emgefreek war `http://localhost:4317/`.
