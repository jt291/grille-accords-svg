# Grille Accords SVG

[English](README.EN.md) · [العربية](README.AR.md) · [Brezhoneg](README.BR.md) · [中文](README.ZH.md) · [Français](README.FR.md) · [हिन्दी](README.HI.md) · [Kurdî](README.KU.md)

Danasîna nivîsî ya kurt veguherînin grideke akordan a zelal û lêdanbar, amade ji bo pratîkê, çapkirinê, guhdarîkirinê û derxistinê.

## Taybetmendî

- edîtor bi hejmarên rêzan, cihê nîşankerê û ronîkirina rêza çalak
- teşxîsên astengker ku rêz, cih û nîşana şaş diyar dikin
- pêşdîtina SVG, transpozîsyon û lêdana Web Audio bi metronomê
- derxistina nivîs, SVG, PNG, WebP, MIDI û MusicXML
- çap, dîmendera tijî, panelên guhêrbar û modên ronî/tarî
- navrû û alîkarî bi heft zimanan

## Sazkirin

Pêşî [Node.js](https://nodejs.org/) û [pnpm](https://pnpm.io/installation) saz bikin, paşê van gavan bi rêzê bixebitînin:

```sh
git clone https://github.com/jt291/grille-accords-svg.git
cd grille-accords-svg
pnpm install
pnpm dev
```

Sepan bixwe li `http://localhost:4317/` vedibe.

## Fermanên bikêr

```sh
pnpm test
pnpm check
pnpm build
pnpm preview
```
